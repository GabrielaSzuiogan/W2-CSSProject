# W2-CSSProject

Week 2: HTML-CSS practice project about Pokemons. You can search a pokemon and/or click on it to discover some information about them.

## Live preview
Open index.html in your browser to view the project locally or can access it by clicking on Deployment. 


## Getting started (local)
1. Clone the repository:
   git clone https://github.com/GabrielaSzuiogan/W2-CSSProject.git
   
3. Change into the project directory:
   cd W2-CSSProject
   
4. Open index.html in your browser:
   - Double-click index.html or
   - Use a local dev server (recommended):
     - Live Server (VS Code extension)


## Project structure
- index.html — main HTML file
- css/ — stylesheet(s) (e.g. styles.css, variables.css)
- images/ — image assets
- README.md — this file
